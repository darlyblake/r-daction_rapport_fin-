# Mémoire de fin de licence — UNG

Ce dépôt contient la version de référence du mémoire de fin de licence :

- **Fichier principal :** `Projet_fin_licence_UNG_version_HTML_corrige.html`
- **Publication :** GitHub Pages
- **Ressources utilisées par le document :** `assets/embedded/`, `captures/` et `diagrammes/exports/`

Le workflow `.github/workflows/deploy-pages.yml` publie ce fichier comme page d'accueil du site (`index.html`). Pour mettre à jour le mémoire, il faut donc modifier le fichier principal ou les ressources qu'il utilise, puis pousser les changements sur la branche `main`.

Les dossiers `diagrammes/sources/` conservent les sources modifiables des schémas. Les dossiers de ressources visuelles sont conservés car le document HTML les référence directement.

La version HTML est la version de référence du mémoire dans ce dépôt. Les anciennes versions et les fichiers de génération d'un rapport PDF séparé ont été retirés afin d'éviter toute confusion.
